# LiDAR Scan Test
Connects to an RPLIDAR-compatible sensor, prints info/health, summarizes scans.
Never commands robot movement.

Install:  python3 -m pip install -r requirements.txt
Run:      python3 lidar_scan_test.py --config ../config.json

Confirm the serial port (/dev/ttyUSB*) and baudrate for YOUR model before running.
