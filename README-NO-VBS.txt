SUMMON DESK — NO-VBS LAUNCHER

1. Extract the entire ZIP folder.
2. Install Node.js 18+ if not already installed.
3. Double-click Start Summon Desk.bat.
4. To use your phone, connect it to the same trusted Wi-Fi and open http://YOUR-COMPUTER-IP:8787/ (replace with your computer's IPv4 address from ipconfig).
5. Double-click Stop Summon Desk.bat when finished.

The bridge may open in a minimized Command Prompt window; leave it running while using the app. If your organization's policy blocks BAT/CMD or PowerShell scripts, ask IT for an approved way to run Node.js rather than bypassing the policy.

Important: the desktop simulator's visual animation is not yet synchronized with the bridge's headless simulation. Phone controls affect the bridge simulation, not validated physical robot hardware. dev-token is for local development only.
